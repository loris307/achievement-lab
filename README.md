# achievement-lab

An empirical test harness for GitHub profile Achievements.

Public guides disagree about which achievements are still obtainable and under
which conditions (own repo vs. foreign repo, self-merge vs. reviewed merge,
self-accepted discussion answers, co-author linking rules).

This repository runs the experiments and records what actually happened.

## Experiments

| # | Achievement | Hypothesis under test |
|---|-------------|----------------------|
| 1 | Pull Shark / YOLO | Does a self-merged PR in a repo you own still count? |
| 2 | Pair Extraordinaire | Which `Co-authored-by:` identities does GitHub link? |
| 3 | Galaxy Brain | Does marking your own reply as the answer count? |

Results are written to `RESULTS.md`.
